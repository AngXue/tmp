# 架算 Scaffold Field

平板优先的脚手架现场测量与材料估算 MVP。应用围绕统一的 `ScaffoldLayout` 构建，打通：

> 二维路径输入 → 参数化构件计算 → 三维人工检查 → 钢管下料与 BOM

## 已实现

- SVG 二维路径编辑器：节点拖动、网格/同轴吸附、路径段新增、真实长度独立录入
- 二维和三维画布全屏模式
- 参数化计算：立杆、纵向水平杆、横向杆、连续剪刀撑、连墙件
- 2～4 排架体配置，横向杆自动贯穿各排连接点
- 管端和立杆顶端外伸参数，材料长度按实际管端计算
- 转角共享立杆去重
- Three.js 轻量三维视图：旋转、缩放、平移、自动居中、构件选择
- 立杆、水平杆、横向杆、剪刀撑、连墙件、钢笆和扣件独立显隐/仅看
- 钢笆铺设层间隔、片数和覆盖面积估算
- 钢管标准长度组合与下料余料估算
- 直角、旋转、对接扣件统计
- 本地项目保存与 JSON 导出
- 材料 CSV 导出及浏览器打印/PDF
- 桌面、平板和移动端响应式布局

## 架构

核心领域模型位于 `src/domain/scaffold.ts`。二维编辑器、三维渲染器和材料视图都消费同一份计算结果，不各自维护构件数据。

```text
ScaffoldPath + Parameters
          ↓
   calculateScaffold
          ↓
    ScaffoldLayout
       ↙       ↘
3D Viewer    Material/BOM
```

## 工程构造参考

当前几何规则按扣件式钢管脚手架的一般构造关系建模，调研参考体系包括：

- `GB 51210-2016`《建筑施工脚手架安全技术统一标准》
- `JGJ 130-2011`《建筑施工扣件式钢管脚手架安全技术规范》

模型已经体现以下几何事实：杆件穿过扣件连接中心并在端部留有外伸；横向水平杆贯穿所有立杆排；钢笆位于横向水平杆支承层；剪刀撑在外侧立面自底至顶分区连续布置；扣件与具体杆件连接点关联。

默认外伸量、排数、钢笆铺设层间隔和剪刀撑跨数只是估算初值，不表示自动满足上述标准。标准适用版本、地区要求、荷载、地基、连墙件、开口、转角、作业层防护及专项施工方案仍须由具备资质的工程人员确认。

## 当前边界

这是规则可配置方向的产品原型，目前构件布置和下料采用通用启发式算法，尚未实现立杆基础、扫地杆、护栏、挡脚板、安全网、施工荷载和结构承载力验算。结果用于现场测量和材料估算，不替代结构安全验算、正式施工设计、专项施工方案或施工图。
